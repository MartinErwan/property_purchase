# Application web (PWA)

À venir au jalon 2 (voir `CLAUDE.md`) : Vite + React + TypeScript + MapLibre GL JS.

L'application est statique : elle lit les fichiers produits par `scripts/11_export_app.py` dans
`data/app/` (jalon 1) et fait tous les calculs (filtres, financement, temps de trajet) dans le
navigateur.
